# Choner brand colour update

The mobile app theme was aligned to the latest Choner website direction:

- **Deep navy background**: `#031A2D`
- **Primary orange CTA**: `#FF8A1F`
- **Warm orange highlight**: `#FF9D45`
- **Muted light text**: `#A5B6C8`
- **Card surfaces**: `#082743`, `#0C3152`, `#13446C`
- **Borders**: `#16507E`

These colours are applied centrally in `constants/theme.ts` so the entire app inherits the updated brand feel.
