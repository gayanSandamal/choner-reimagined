Find & Challenges, end to end: landing to shared streak

One buildable sequence that reconciles every locked decision, now split across the two tabs that actually own it. Tap through the phone, jump to any phase on the left, and switch who is looking to see both sides of each negotiation.

3. No Solo modeEvery path leads to Run together or Run separately, together.
4. Two tabs, one journeyLanding through Match Found stays in Find, which then always shows the matched partner (photo, Report/Block) for as long as the pairing exists — never the radar again. Say Hi onward, planning, the session, check-in, lives in Challenges.
